# Сайт Дмитрия

Рабочая статическая версия сайта Дмитрия: HTML, CSS и vanilla JavaScript без сборщика.

## Как открыть локально

Из этой папки можно открыть `index.html` напрямую или запустить локальный сервер:

```bash
python3 -m http.server 8010
```

После запуска сайт доступен по адресу:

```text
http://127.0.0.1:8010/
```

## Основная структура страниц

- `/` — главная
- `/diagnostika-otnosheniy/` — диагностика отношений
- `/taro-na-otnosheniya/` — таро на отношения
- `/posle-ssory/` — помощь после ссоры
- `/lyubovnaya-rabota/` — индивидуальная любовная работа
- `/zaschita-ochischenie/` — защита и очищение
- `/stoimost/` — стоимость
- `/o-dmitrii/` — о Дмитрии
- `/faq/` — вопросы и ответы
- `/kontakty/` — контакты
- `/privacy/` — политика конфиденциальности

## Что нужно подтвердить перед финальной публикацией

- реальные фото и видео Дмитрия;

## Формы, согласие и Google Ads

Настроено 2026-08-09:

- на основной форме и в попапе есть обязательное согласие со ссылкой на `/privacy/`;
- политика конфиденциальности описывает фактический маршрут заявки: сайт -> API -> Telegram Дмитрия;
- событие `form_submit` отправляется только после успешного ответа API (`HTTP 200`), поэтому ошибки отправки не считаются лидами;
- перед этим событием Google tag получает только номер телефона и только после согласия пользователя; имя, описание ситуации и выбранный мессенджер в Google Ads не передаются;
- Google tag (`AW-18266144457`) хеширует номер для расширенного сопоставления конверсии; существующий триггер и основная конверсия `form_submit` не меняются;
- для этой схемы не нужны отдельные пользовательские переменные GTM для расширенной конверсии. Рабочая область GTM после настройки должна оставаться без таких черновиков.

Перед расширением рекламы на страны ЕЭЗ нужно отдельно внедрить Consent Mode v2 и проверить текст политики применительно к целевым странам.
